# BLACK Android — preparador local

Variante independente do port Android de [RanggaCasper/Black-Android](https://github.com/RanggaCasper/Black-Android), baseada na tag v1.5.0 (commit f3754d6985a8c35204e7df071546e586b10f1806).

Publicação em preparação. O APK final será disponibilizado após as verificações de compilação, assinatura e download.

O app terá uma tela de preparação com download, progresso, pausa/retomada e validação SHA-256. Os dados permanecem separados do APK. O identificador Android é com.local.black.downloads; o atualizador oficial foi desativado.

## Créditos

Port e motor nativo: RanggaCasper e contribuidores; [XboxXBE-Recomp](https://github.com/TGP482/XboxXBE-Recomp); [SDL](https://github.com/libsdl-org/SDL). O ícone é preservado do port. Este repositório não é o projeto oficial.
